# Quadrata: Architectural 9x9 Geometric Block Puzzle

Quadrata is an architectural geometric block puzzle that combines timeless polyomino placement with precision-engineered 9x9 Sudoku sub-quadrant mechanics[cite: 1]. Grounded in a sleek, volcanic glass aesthetic and tuned for absolute focus, it features fluid drag-and-drop physics, multiple game modes, and procedural Web Audio synthesis[cite: 1].

---

## Features

* **Sudoku Sub-Quadrant Mechanics**: Clear horizontal rows, vertical columns, and 3x3 macro boxes simultaneously to build exponential streak multipliers[cite: 1].
* **Four Distinct Game Modes**:
* **Classic 9x9**: Unrestricted contemplative logic with no ticking clock.
* **Blast Rush**: A 45-second high-adrenaline timed mode where every clearing chain adds crucial seconds back to the clock.
* **Tactical Matrix**: Face strategic fixed obsidian obstacle stones that must be cleared by completing surrounding sectors.
* **Zen Sanctuary**: A zero-fail state mode where the board gently exhales and reorganizes when no moves remain, accompanied by ambient soundscapes.


* **Procedural Audio Engine**: Built-in Web Audio API synthesizer producing tactile glass chimes, snap impacts, and binaural soundscapes (Glass Rain, Deep Synth, Silent Void)[cite: 1].
* **Ergonomics & Accessibility**: Fully customizable keyboard shortcuts (Arrow keys, WASD, and custom binding maps), high-contrast colorblind assistance with geometric inner-glyphs, and adjustable pickup rack docking (Left, Right, or Bottom).

## Tech Stack

* **Framework & Build**: React 19, TypeScript, Vite
* **Styling**: Tailwind CSS v4
* **Audio & Animation**: Native Web Audio API, Canvas Confetti

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
```bash
npm install

```


2. Configure your environment variables if necessary (copy `.env.example` to `.env` or `.env.local`).
3. Run the development server:
```bash
npm run dev

```
